Project Overview (complete)
This repository contains the Portfolio of Evidence (PoE) for the WEDE5020 module. Two target
organisations were proposed for lecturer approval:
	1.	Bright Beginnings Community Trust which is a non-profit organisation supporting underprivileged
children through after school tutoring, a daily meal programme, and school supply drives.
	2.	Thandeka’s Artisan Home Decor: a retail store selling handmade, locally sourced home
decor including ceramics, textiles, woven baskets, and candles.
Initial HTML structures have been built for both organisations ahead of lecturer approval, once approved was confirmed, development was continued 
on the approved organisation only.
