Project Overview 
This repository contains the Portfolio of Evidence (PoE) for the WEDE5020 module. Two target
organisations were proposed for lecturer approval, Bright Beginnings Community Trust
(non-profit) and Thandeka's Artisan Home Decor (retail store), in line with Section 2.2 of the
brief. **Thandeka's Artisan Home Decor** was taken forward, and the website has been built for
this organisation: a retail store selling handmade, locally-sourced home decor including
ceramics, textiles, woven baskets, and candles.

The site currently consists of five static HTML pages (Homepage, About Us, Products, Enquiry,
Contact), an external stylesheet, a small JavaScript file for the mobile navigation menu, and an
`images/` folder holding all visual assets.

Website Goals and Objectives
- Create a functional, visually appealing, and easy-to-navigate website for the store.
- Clearly communicate the store's mission, product range, and contact details.
- Provide a working enquiry pathway for stock availability, custom orders, and general
  questions.
- Build the site using clean, semantic, standards-compliant HTML, with CSS and JavaScript
  layered on in Part 2 and Part 3.

Key Features and Functionality
- Five core pages: Homepage, About Us, Products, Enquiry, Contact.
- Consistent, functional navigation menu across all pages, with a mobile hamburger toggle
  (`js/main.js`).
- Product enquiry form (stock availability, custom orders, general enquiries) and a separate
  general contact form.
- Contact page with two physical locations and an embedded map.
- Semantic HTML structure (`header`, `nav`, `main`, `section`, `footer`) throughout, with
  descriptive comments explaining each section's purpose and how components are reused
  across pages.
- Low-fidelity wireframes for all five pages (see `wireframes.md`), used to plan the layout
  before development.

Part 1 Details
Part 1 - Building the Foundation: Project Initiation and Planning, covers the Website Project
Proposal, content research and sourcing plan, wireframes, sitemap, file/folder structure, and
initial HTML structure. All Part 1 deliverables have been completed for Thandeka's Artisan Home
Decor, including the corrections logged in the Changelog below following lecturer feedback.

Part 2 Details
Part 2 — Designing the Visuals: CSS Styling and Responsive Design — covers implementing Part 1
feedback, building an external stylesheet with base styles, typography, and layout (CSS
Grid/Flexbox), visual styling (colour, borders, box-shadow, interactive pseudo-classes), and
responsive design (breakpoints, relative units, responsive images). This section will be
expanded with screenshot evidence across desktop/tablet/mobile as Part 2 work is completed.
